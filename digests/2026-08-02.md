# 毎朝AI/ITダイジェスト — 2026年8月2日(日)

今日はモデル・開発ツール・エージェント基盤の3領域から、韓国LG AI Researchの巨大MoEモデル公開、GitHub CopilotのVS Code 7月アップデート、AnthropicがClaude本体に新MCP仕様を実装した件を取り上げる。

## 1. LG AI Research、750BパラメータのMoEモデル「K-EXAONE 2.0」をApache 2.0で公開

**情報源・日付**: The Korea Times (2026-07-31)、Hugging Face (LGAI-EXAONE/K-EXAONE-2.0-750B-A37B)、Seoul Economic Daily (2026-08-01)

**何が新しいか**: LG AI Researchが韓国最大となる7500億(750B)パラメータのMoEモデル「K-EXAONE 2.0」をHugging Faceで公開した。前モデルK-EXAONE 1.0からパラメータ数が3倍以上に拡大し、ライセンスはApache 2.0で商用利用も無制限。

**技術的なポイント**: アーキテクチャはMixture-of-Experts構成で、256個の専門家(エキスパート)モジュールのうちトークンごとに8個を動的に選択して起動する仕組み。総パラメータ750Bに対し、推論時に実際に活性化するのは37B(モデル名の"A37B"はこのActive 37Bを指す)。対応言語は韓国語・英語・スペイン語・ドイツ語・日本語・ベトナム語・フランス語・イタリア語・ポルトガル語・ポーランド語の10言語に拡大。24種のベンチマーク平均スコアはK-EXAONE 1.0の63.3から70.1へ約10%向上し、コーディング・エージェント系ベンチマーク3種の平均では約30%の性能向上を報告している。

**なぜ重要か**: 750B級・Apache 2.0ライセンスのオープンウェイトMoEモデルが増えることで、自前でホスティングしてファインチューニングやエージェント基盤に組み込む選択肢が広がる。特に「コーディング・エージェント系ベンチマークで30%向上」という数値は、自社インフラでLLMを動かしたいFDE/SA的なロールにとって、クローズドAPI依存を減らす具体的な代替候補として注目に値する。

**リンク**: https://huggingface.co/LGAI-EXAONE/K-EXAONE-2.0-750B-A37B / https://www.koreatimes.co.kr/business/tech-science/20260731/lg-unveils-750-bil-parameter-frontier-ai-model-k-exaone-20

## 2. GitHub Copilot、VS Code向け2026年7月アップデート — Agentsウィンドウ刷新とCopilot CLIのサンドボックス制御強化

**情報源・日付**: GitHub Changelog「GitHub Copilot in Visual Studio Code, July 2026 releases」(2026-07-30)

**何が新しいか**: VS Code 1.127〜1.131にかけての一連のリリースで、エージェント作業・コードレビュー・チャット・ナビゲーションが強化された。プレビュー中の「Agentsウィンドウ」がレイアウト刷新と複数セッション管理の改善を受け、レビューワークフローも高速化。

**技術的なポイント**: エディタパネルが刷新され、ファイル/diffをチャットと同じタブバー内で開けるようになり、ファイルごとの追加・削除行数がコンパクトなdiff表示で見られるようになった。実験的機能として、Agentsウィンドウ内でMarkdownファイルを直接編集し、エージェントに処理させるコメントを付けられる機能も追加。Copilot CLI側では、条件付きサンドボックスバイパス、Ctrl+Gによる自由入力編集、ネイティブMDM設定経由でのマネージドサンドボックスポリシーに対応した。アクセシビリティ面ではチャット・エディタ・統合ターミナルで使える組み込みディクテーション(音声入力)機能も追加され、Copilotによる書き起こしの整形・フィラーワード除去にも対応する。

**なぜ重要か**: エージェント型コーディングツールの実務利用では「複数エージェントセッションの管理」「レビュー時のdiff可視性」「CLIのサンドボックス制御」がボトルネックになりやすい。今回のアップデートはまさにその運用面の摩擦を減らす方向の改善であり、企業導入時のセキュリティポリシー(MDM連携)にも踏み込んでいる点は、エージェント運用を任される立場になったときに押さえておきたい実装パターン。

**リンク**: https://github.blog/changelog/2026-07-30-github-copilot-in-visual-studio-code-july-2026-releases/

## 3. Anthropic、Claude本体に新MCP仕様(2026-07-28)を実装 — MCP月間SDKダウンロードが4倍の4億超に

**情報源・日付**: Claude公式ブログ「MCP 2026-07-28 spec: stateless core, coming to Claude」、36Kr報道(いずれも2026-07-28前後)

**何が新しいか**: 7/28に確定した最新のMCP仕様(ステートレス化・Extensions枠組み・認可強化)をAnthropicがClaude本体に取り込み始めた。あわせて、MCPの月間SDKダウンロード数が年初来4倍に増え4億回を突破したと報告している。

**技術的なポイント**: Claude側ではMCPコネクタに、埋め込みUI(MCP Apps経由のサーバーレンダリングUI)、エンタープライズ管理認証、可観測性、プライベートネットワークトンネルといった機能が追加される。MCP Appsはサンドボックス化されたiframe内で動作し、ClaudeとアプリのやりとりはpostMessage経由の監査可能なJSON-RPCメッセージで行われ、すべてのアクションにユーザーの明示的な承認が必要という設計。Amplitude・Asana・Box・Canva・Clay・Figma・Hex・monday.com・Slackなどが対応済みで、Salesforceも対応予定。

**なぜ重要か**: MCPがコネクタ標準として実質的に業界標準化しつつあることを、ダウンロード数4倍という具体的な数字が裏付けている。エージェント開発でMCPサーバーを書く/選定するスキルは、FDE的な役割でクライアント企業のシステムとLLMエージェントを繋ぐ際にそのまま使える実務スキルであり、この仕様更新(ステートレス化・認可強化)を理解しておくことは実装の前提知識になる。

**リンク**: https://claude.com/blog/bringing-mcp-2026-07-28-to-claude
